# SEO

Public profiles and Personal Spaces should expose stable public URLs, descriptive metadata, canonical URLs, Open Graph cards, sitemap entries, and structured data where appropriate.

Private content, admin pages, settings, authentication pages, and sensitive user data must not be indexed. Public profile and space rendering should remain responsive and should not rely on client-only metadata generation.

Custom domains are an architecture roadmap item. Domain verification, DNS mapping, SSL, and redirect behavior require implementation and hosting configuration before being advertised as live.
